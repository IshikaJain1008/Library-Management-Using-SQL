# 📚 **Library Management System | SQL Data Analytics Project**

**🚀 Project Overview**
This project is a complete Library Management System built using MySQL with a strong focus on data analysis, database design, and business problem solving.

The project simulates the real-world operations of a library including:

* Book issuance and returns
* Member management
* Employee and branch handling
* Rental revenue tracking
* Overdue book analysis
* Fine calculation
* Book availability automation using Stored Procedures

A complete SQL project simulating a real-world library management system — covering everything from basic CRUD operations to stored procedures, CTAS, and business logic automation.

# 🏗️ Database Architecture

Six relational tables connected through foreign key constraints:

**branch** — Library branch details, manager info, and contact number

**employee** — Staff records with position, salary, and branch assignment

**books** — Book catalogue with category, rental price, and availability status

**members** — Registered member profiles and registration dates

**issued_status** — Every book issuance record: who issued it, when, and by which employee

**return_status**  — Return records with book condition tracking

# 📊 Business Problems Solved

The project contains 20 SQL business questions/tasks designed to simulate real-world library operations and reporting requirements.

✅ Task 1: Add New Book Records

Inserted new book records into the library inventory.

✅ Task 2: Update Existing Member Information

Updated member address records dynamically.

✅ Task 3: Delete Issued Book Records

Removed specific issuance records from the system.

✅ Task 4: Retrieve Books Issued by Specific Employees

Analyzed which books were issued by a particular employee.

✅ Task 5: Identify Members Issuing Multiple Books

Found members who issued more than one book.

✅ Task 6: Create Summary Tables Using CTAS

Generated analytical summary tables using CREATE TABLE AS SELECT.

✅ Task 7: Retrieve Books by Category

Filtered books based on categories such as Fiction, Classic, etc.

✅ Task 8: Calculate Rental Revenue by Category

Computed total rental income generated by each category.

✅ Task 9: Identify Recently Registered Members

Retrieved members registered within the last 180 days.

✅ Task 10: Employee & Branch Manager Reporting

Generated reports combining employees, branches, and managers.

✅ Task 11: Create Premium Rental Book Table

Created a separate table for books with rental prices above a threshold.

✅ Task 12: Find Books Not Yet Returned

Identified books currently issued but not returned.

Identified members with overdue books beyond the allowed return period.
